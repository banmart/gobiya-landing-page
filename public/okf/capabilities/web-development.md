# Web Development

Gobiya builds fast, modern websites — described as blazing-fast React builds — engineered for both search ranking and conversion. The builds can ship with native CRM and blockchain integration rather than bolted-on third-party tools.

## What it covers

- Modern React site builds focused on speed and conversion.
- Integrated [Native CRM](/capabilities/native-crm.md) for lead capture.
- Optional [Blockchain & Web3](/capabilities/blockchain-web3-development.md) features.

## Typical outcome

A dental practice reported patient inquiries growing 5x after launching a new platform that combined native CRM integration with fast React builds. See [SmileCenter Dentistry](/case-studies/smile-center-dentistry.md).
